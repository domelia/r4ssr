# r4ssr

<!-- badges: start -->

<!-- badges: end -->

Пакет «r4ssr» («R for social science research») содержит сборник
интерактивных практических (самостоятельных) работ для курса *«Анализ
данных в R»* для студентов магистерской программы Института гуманитарных
наук Алтайского государственного университета направления 39.04.01
Социология, профиль «Цифровые методы анализа и визуализации данных в
социальных исследованиях.

Пакет является дополнением к электронному учебному пособию [*R в
социологических исследованиях*](https://domelia.github.io/R-book.html) и
[*курсу видеолекций*](https://rutube.ru/plst/1426461?r=wd).

## Установка

Пакет доступен только в версии разработчика. Установить пакет `r4ssr`
можно из репозитория [GitHub](https://github.com/) с помощью следующего
кода:

``` r
# install.packages("pak")
pak::pak("domelia/r4ssr", dependencies=TRUE)
```

## Пример использования

Интерактивные тьюториалы запускаются с помощью пакета `learnr`:

``` r
learnr::run_tutorial("Assignment0", package="r4ssr")
```
